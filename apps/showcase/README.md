# ByteSphere UI standard: showcase and component library

A Vite + React + Tailwind v4 app that renders the standard in `../../docs` with the real generated tokens, and doubles as the reusable component library.

```bash
# run from the repo root (npm workspaces)
npm install
npm run dev        # http://localhost:5173   (?theme=dark&dark=navy&radius=soft&nav=ink for review links)
npm run build      # type-check + production build
npm test           # Playwright + axe
npm run catalog    # regenerate COMPONENTS.md, AI-INDEX.md, catalog.json in packages/ui/catalog
```

## Reusing components (people and AI)
1. Open **Kits → Component catalog** in the app. Search by what you need, preview it, then copy **Import**, **Usage** or **AI prompt**.
2. Or read `packages/ui/catalog/AI-INDEX.md` ("I need… → use…") and `COMPONENTS.md` beside it. Both are generated from `packages/ui/catalog/catalog.data.ts`.
3. Import everything from one place: `import { Button, SideNav, StatTile, ProductCard } from "@bytesphere/ui"`.
4. Giving an AI a component: paste the card's **AI prompt**, or point the agent at the repo-root `AGENTS.md` and say "use the components listed there". Rules are included in every prompt.
Adding a component: write it in the right file, add an entry to `catalog.data.ts` (summary, intents, variants, props, snippet), add a preview in `apps/showcase/src/catalog/previews.tsx`, run `npm run catalog`.

## Rules this app follows
Tokens only · one primary action per view · four states on every data surface · visible 2px focus ring · labels above fields · sentence case · Lucide icons only · `<Logo>` for the name · blur and transparency only where `surfaces-backgrounds-footers.md` allows. Sample names, customers and figures are invented for demonstration.
